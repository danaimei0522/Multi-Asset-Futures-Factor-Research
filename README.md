# Multi-Asset-Futures-Factor-Research

RB / AU / CU / AG 三条件共振趋势研究。按用户规则、通过 Codex 辅助编写的 Python 日线模拟框架与研究文档；不是 PandaAI SDK、平台策略副本或已验证的交易系统。

**PandaAI 平台报告与独立结果严格分开。** 用户提供的平台区间为 2023-01-01 至 2026-07-01，总收益 126.03%、年化 27.32%、夏普 0.80、最大回撤 37.71%、交易次数 329。未独立复现，未完成样本外验证。329 的订单、成交或往返统计口径未知。

本项目目前没有真实市场数据，也没有独立市场业绩。合成测试结果只证明被测试的软件行为，不能作为策略有效性证据。
