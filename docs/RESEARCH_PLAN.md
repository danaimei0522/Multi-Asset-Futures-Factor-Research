# 研究计划、泄露控制与局限

1. 冻结规则：登记用户规则与独立假设，保留变更记录。取得完整平台配置、权益和订单流水后再判定差异，不倒推参数凑收益。
2. 数据审计：真实合约、历史可知路由、交易日历、夜盘、缺失、交割限制、预热。禁止事后主力标签与跨合约拼接 ATR。
3. 独立基准：2023-01-01 至 2026-07-01，统一端点、费用及本金。逐笔核查开平、止损和换月，再计算组合指标。
4. 成本与成交压力：零成本只作诊断；正式基准为已核验费用，压力情景增加滑点、延迟成交及换月摩擦。延迟成交和动态成本需扩展当前引擎后再运行。
5. 稳健性：MA/突破/ATR 周期邻域、止损 2/3/4 ATR、分品种、分年份、多空归因、移除任一品种、不同可知换月路由、收益集中度、回撤重叠、保留时间依赖的分块重采样。当前 window 同时控制三个窗口；独立窗口实验需先拆分配置。
6. 样本外：平台区间已经被观察，同区间重新切分不能自动称为真正未见样本。记录参数试验数，训练/验证之外封存最终测试段，必要时前向纸面观察。后续日期是否未见必须有研究记录支持。

泄露控制：突破窗口排除信号日；收盘指标次日才可执行；旧止损不使用当日完整数据回溯更新；新合约用自身历史；路由按已知时间；合成前缀不变性测试检查追加未来数据不改变过去输出。开盘模拟不读取当日最终成交量；实际能否成交仍需交易状态或盘中数据证明。

指标：权益日收益简单均值/样本标准差计算 Sharpe，零无风险利率，年化 252；年化收益按执行期输入交易日数，最大回撤包含初始权益。平台公式未知。应在正式研究另报交易日覆盖、成交数、完整往返数、成本、保证金、敞口和未平仓，当前引擎仅提供基础指标与成交台账。

主要局限：三条件并不保证三个独立因子；成交量>0不衡量量能增强。固定2手不等风险，贵金属相关性、行业共同波动和本金设定会影响组合。已有平台报告有选择偏差，未知参数试验次数；无真实数据时不能得出有效性、稳健性或可交易性结论。当前框架未完成交易所级撮合、历史动态费用、结算价、强平、利息及容量研究。
