# 审计修复记录

策略不变：MA20、此前20根突破、成交量>0、ATR20简单平均×3固定止损、每品种2手、60根预热、持续共振、换月先平后按信号开仓。未为提高收益调参。本记录不构成平台复现认证。

| 项目 | 修复前 | 修复后 |
|---|---|---|
| 多品种资金 | 此前新仓滑点尚未进入权益，可能多批订单后才收盘报错 | 每次入场立即扣费用/滑点，按开盘统一估值和保证金，后续订单重新检查 |
| 空仓保证金 | 按更低的卖出成交价计算新仓需求 | 按当前开盘市场参考价计算，与已有仓一致 |
| 研究品种 | 随当天有行情的品种变化，整个品种缺失可能忽略 | 默认固定四品种，只有显式配置才允许子集；缺品种拒绝 |
| 日历 | 从行情日期集合推断，整日缺失难发现 | 必须外部日历；缺任何日历交易日的品种覆盖拒绝 |
| 连续性 | 历史内部缺口和退出陈旧信号未统一检查 | 每合约记录首尾间连续；入场/持仓历史统一检查截至上一交易日 |
| 新合约 | 60根预热 | 保留60根，不足不入场；正常新上市短历史不伪造补齐 |
| 异常输入 | NaN本金、小数手数、非规范日期可能通过 | 有限值、整数、日期、区间、日历唯一有序、配置品种均校验 |
| 止损+换月 | 跳空止损优先但冲突未专门记录/测试 | 保留优先级，平一次并阻止当日换月开仓，输出原因事件 |
| 换月后旧仓止损 | 正常开盘平旧仓，缺少冲突回归测试 | 保留顺序，测试保证旧仓日内高低价不影响换月成交 |
| 新仓止损已越过 | 极端滑点下可能假设在更有利的止损价退出 | 立即按开盘加退出滑点处理，不能获得虚假的止损线价格 |
| 无效权益 | 主要收盘保证金检查，指标可接收异常权益 | 开盘阶段/收盘资金检查，无效运行失败；指标拒绝非正/非有限权益 |

合成算术回归：三品种初始权益990，开盘160、每品种2手、乘数10、保证金10%、滑点0.5、费用每手1。旧实现批准三笔，收盘权益954<保证金960后失败；新实现只开AG/AU两笔，CU因资金不足被拒绝，收盘权益966、保证金640。上述金额仅为单元测试，不是市场收益。

测试由22项扩展至49项，包含多空资金边界、缺品种/交易日/历史、止损与换月冲突及固定ATR公式。原有22项断言仍保留，仅适配显式日历和单品种测试集合。完整结果见 ../TEST_RESULTS.md。

仍未解决的研究限制：日线真实成交可行性、盘中强平、历史动态费率和保证金、真实结算价、合约生命周期和时点数据来源核验。没有独立真实市场业绩，更没有验证平台报告或样本外有效性。
