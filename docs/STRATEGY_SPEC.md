# 策略规范与平台无关伪代码

基准采用日线，每个品种目标 2 手，最多一个方向。价格指完成日 K 线的收盘价。MA20 包含信号日；突破窗口为信号日前 20 根最高/最低价，不含信号日。严格大于/小于，等号无信号。多空均要求 volume > 0，该条件是数据有效性过滤，不是独立的量能预测因子。

每个实际合约至少 60 根完整 K 线。ATR20 使用 20 根真实波幅的简单平均，不是 Wilder 平滑；TR=max(H-L,abs(H-prev_close),abs(L-prev_close))。入场使用前一完整交易日的 ATR，止损距实际成交价 3 ATR，固定不跟踪。多仓止损 entry-3ATR；空仓 entry+3ATR。ATR 非正则不入场。指标、平滑和止损形式为独立基准假设，平台未确认。

持续持仓每天必须满足同方向全部条件，否则下一交易时点平仓。突破只在入场时检查、动态 ATR、移动止损均不属于此基准。

```text
每一交易日开盘：
    依据独立日历验证固定品种集合、路由、历史连续性、旧仓与目标合约行情完整
    全部旧仓按开盘标记，汇总账户权益；每笔新仓立即扣费用与滑点并标记到开盘
    先处理旧仓跳空止损，再处理换月与共振失效平仓
    对每个空仓品种，以目标合约上一交易日完整历史计算信号
    若旧仓已平、预热足够、保证金允许：按开盘加不利滑点开 2 手
    跳空止损当天禁止该品种重入
日内：
    依据开盘前已有或新入场建立的固定止损检查高低价
    触及则按止损加不利滑点模拟成交，不当日重入
收盘：
    按收盘结算持仓盈亏、保存权益与保证金
    将当日 K 线加入历史，供下一交易日使用
```

反向信号先平后开。换月按交易日前已知路由，先平旧合约，再用新合约自己的历史信号决定是否同日开新仓；不足 60 根不新开。换月无条件平旧仓，不将跨合约价差直接记为利润。各次平开独立收费。止损和换月同时发生时止损优先，跳空止损当日不重入；此优先级需要对照平台核实。
